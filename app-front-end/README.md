# Aethria Application

Main investment intelligence application for institutional allocators.

## Development

```bash
npm install
npm run dev
```

Runs on `http://localhost:3000`

## Structure

- `src/components/` - Application components (WorkGrid, InvestmentMemo, etc.)
- `src/layout/` - Design system layout components
- `src/design-system/` - Tokens and design primitives
- `src/data/` - Mock data and types

## Note

The waiting list page has been moved to `web-front-end/` as a separate project.
