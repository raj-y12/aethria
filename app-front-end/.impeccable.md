## Design Context

### Users
Small VC firms to institutional fund managers. Sophisticated operators who run deal pipelines at volume. They live in Bloomberg, Notion, and Excel — they trust interfaces that don't explain themselves. Speed of triage matters. Signal clarity matters. They will not forgive a slow or noisy UI.

### Brand Personality
**Decisive. Institutional. Unsentimental.**

The interface should feel like a top-quartile VC fund's internal ops tool — not a startup's product demo. Think: the ops dashboard a Sequoia or Benchmark partner would actually use internally. Zero decoration for its own sake. Every pixel is accountable.

### Aesthetic Direction
- **Theme**: Dark oxford (#002147) chrome / navigation, warm paper (#F2F0EA) content surfaces
- **Typography**: EB Garamond for editorial headers/display; Geist Sans for body/UI; JetBrains Mono for all data, labels, metadata
- **Palette**: Oxford navy dominant. Paper warm. Heritage gold (#b8976a) for hairlines and structural accents (not badges). Burgundy (#7D2B3A) for escalations only — treat it like a fire alarm.
- **No rounded corners. No shadows. No glassmorphism. No gradient text.**
- **Borders**: 1px hairlines only. Let space and type do the separating, not boxes.
- **Data**: Tabular numerals throughout. Numbers should feel financial — JetBrains Mono, slightly larger than surrounding text, tabular-nums.
- **Density**: Lean dense but not cramped. The goal is "I can triage 50 deals before lunch" — information at a glance, detail on demand.

### Design Principles
1. **Signal before chrome** — if a user's eye lands on a decorative element before data, that's a failure
2. **Earned restraint** — whitespace is a choice, not a default; use it to create hierarchy, not comfort
3. **Financial legibility** — numbers in mono, tabular; decisions (YES/NO/MAYBE) in Oxford at full opacity; everything else stepped down
4. **Institutional confidence** — the UI should not beg for attention; it should simply work, quietly and precisely
5. **Progressive disclosure** — summary in the row, detail in the memo; never repeat yourself across levels
