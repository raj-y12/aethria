Audit Summary

The embedded workspace memo (~517px column) tries to be a full IC pack. Recent session fixes improved cover stacking, ruling copy, and precedent borders — but structural issues remain: duplicated content, ruling buried below the fold, and too many open sections before the GP can act.

Section order today (InvestmentMemoContent.tsx)

  1. Cover: title, standfirst, prior rulings, portfolio signals, recommendation, brief (full only)
  2. Snapshot + next move (embedded)
  3. Why Now, What Limits Conviction, Scoring, Reviewer Consensus, Reviewer detail, Risks
  4. Your ruling ← action surface
  5. Disclosures: partner rationale, decision ledger, sources, run log

Already improved (this session)

  • Embedded cover: stacked snapshot rows, split conviction/consensus lines, hide cover brief
  • Ruling section: removed intro, numbered steps, verbose risk gate, submit row border
  • Precedent cards: no borders, no name underline on hover

Prioritized Recommendations

P0 — Embedded workspace (highest leverage)

  • Move ruling up. Place MemoRulingSection immediately after snapshot/next move. Escalated deals need Invest/Monitor/Pass without scrolling past scoring and risks.
  • Collapse the deep dive in embedded. Wrap Why Now, Killers, Scoring, Consensus, Reviewer detail, and Risks in a single collapsed “Analysis” disclosure (or hide until expanded). Keep cover + snapshot + ruling visible by default.
  • Deduplicate conviction blockers. “What limits conviction” appears in snapshot (buildSnapshotRows) and again in memoKillers. Pick one surface in embedded — keep snapshot row OR killers section, not both.
  • Deduplicate reviewer consensus. Cover already shows “Reviewers aligned/split”. Hide memoConsensusSection in embedded or fold into cover only.
  • Precedent trim. Remove memoPrecedentLead (“One deal you already decided…”) and “Open deal →” — the card is already a link. Keep collapsed by default.
  • Reorder cover. Recommendation before prior rulings/portfolio signals so the eye hits MONITOR/INVEST/PASS first, context second.

P1 — Both embedded and full memo

  • Single precedent surface. Precedents appear on cover (MemoPrecedentStrip) and again in decision ledger disclosure. Remove ledger duplicate list.
  • Stack label/value everywhere narrow. Use @container on .memoPanel so snapshot/brief rows stack when column < ~560px, not only in --embedded or viewport 640px.
  • Reduce mono label noise. Reserve uppercase mono for section heads only; body labels (blocker, next move, tags) use sentence case or smaller caps.
  • Portfolio signals. 3-column grid breaks in narrow column — stack like snapshot in embedded.
  • Remove redundant borders. Audit remaining border-top on precedent, portfolio context, killer list, consensus list, disc groups — use whitespace rhythm instead (user rejected card/tag borders).

P2 — Full memo page polish

  • Unify cover brief with snapshot on full page too (same as embedded dedupe).
  • Scoring section is heavy; default “Analyst reads” and thesis alignment collapsed unless contested.
  • Reviewer detail contested copy is wordy — one line max.
  • Risks vs killers — merge or cross-link; adverse register + killer list overlap semantically.

P3 — Engineering hygiene

  • Deduplicate CSS. InvestmentMemoContent.css is ~4041 lines with a near-complete duplicate editorial block (~lines 1998–2540 mirror ~1145–1600). Delete duplicate block; ~50% file size reduction.
  • Split component. InvestmentMemoContent.tsx is 1500+ lines — extract cover, analysis cluster, disclosures.
  • Pass embedded to subcomponents for conditional density instead of CSS-only hacks.
